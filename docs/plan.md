# Frontend Development Plan

This document outlines the plan for developing the frontend of the store management system using Next.js and shadcn/ui.

## Phase 1: Project Setup & Core UI

- **Objective:** Set up the Next.js project, integrate shadcn/ui, and create the core layout and components.
- **Key Tasks:**
    - Initialize a new Next.js project.
    - Install and configure shadcn/ui.
    - Create a main layout with a sidebar, header, and content area.
    - Develop a reusable component library/style guide.

## Phase 2: Authentication Module

- **Objective:** Create the UI for user authentication.
- **Pages:**
    - Login
    - Registration
    - Forgot Password
    - Reset Password

## Phase 3: Backoffice Module

- **Objective:** Build the administrative backoffice interface.
- **Pages:**
    - Dashboard
    - Store List
    - Create/Edit Store
    - User List
    - Create/Edit User
    - Invoice List
    - Invoice Details

## Phase 4: Catalog Module

- **Objective:** Develop the product and category management UI.
- **Pages:**
    - Product List (with search and filters)
    - Product Details
    - Create/Edit Product
    - Category List
    - Create/Edit Category

## Phase 5: Inventory Module

- **Objective:** Create the interface for managing inventory.
- **Pages:**
    - Inventory Item List
    - Inventory Item Details
    - Stock Adjustment
    - Stock Movement List

## Phase 6: Purchase Order Module

- **Objective:** Build the UI for managing purchase orders and suppliers.
- **Pages:**
    - Purchase Order List
    - Create/Edit Purchase Order
    - Purchase Order Details
    - Supplier List
    - Create/Edit Supplier
    - Supplier Details

## Phase 7: Sales Order Module

- **Objective:** Develop the UI for managing sales orders.
- **Pages:**
    - Sales Order List
    - Create/Edit Sales Order
    - Sales Order Details
    - Customer List
    - Customer Details
